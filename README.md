# run-bfs-face-swap-on-free-colab

Run **BFS — Best Face Swap** ([Alissonerdx/BFS-Best-Face-Swap](https://huggingface.co/Alissonerdx/BFS-Best-Face-Swap),
~150k downloads/month) — head swap and body swap LoRAs on **Qwen-Image-2.1** —
on a **free** Colab or Kaggle T4, then keep swapping **from any machine**
through a public API URL. Every number in this repo was measured on real free
T4s and every gotcha was paid for in a real failed run. Nothing is aspirational.

Works like our other free-T4 repos:
[run-qwen-image-on-free-colab](https://github.com/KodeIsFun/run-qwen-image-on-free-colab) ·
[run-z-image-on-free-colab](https://github.com/KodeIsFun/run-z-image-on-free-colab).

## The measured table (free T4s, 2026-09-30, seed 42, consent-free synthetic inputs)

| Task | Weights | Wall | s/step | ArcFace sim → reference |
|---|---|---|---|---|
| **Head swap 1024²** | **GGUF Q4_K_M (default)** | **96.1 s** | 10.54 | 0.632 |
| Head swap 1024² | official int8_convrot | 222.2 s | 20.71 | 0.640 |
| Head swap 1408² (the template's own latent size) | official int8 | 477.6 s | 51.96 | **0.429 — identity transfer fails** |
| Body swap 768² | official int8 | 270.3 s | 26.63 | 0.381 (small-in-frame face, as documented upstream) |
| Anchor: the same two-image conditioning, **no BFS LoRA** | official int8 | 168.1 s | 20.26 | **0.867** |

What those rows mean (full write-up in [references/04-tweaking.md](references/04-tweaking.md)):

- **Use the GGUF weights**: 2.3× faster than the official int8 at identical
  quality (beret, freckles, hair boundaries, the background all match).
- **1024² is the T4 sweet spot.** The official template binds both reference
  photos at the latent size (2 MP) — that is a ~40k-token DiT sequence costing
  **258.84 s/step** on a T4, and at that size identity transfer also fails
  (the target's hair stays). This pipeline pre-scales references to
  **768 (scene) / 512 (head)** — the BFS author's own "give the reference
  room, not resolution" rule — and keeps the latent at 1024².
- **The honest identity twist:** with the two-image conditioning working, the
  base model *without the BFS LoRA* already swaps the head (hair included) and
  scores higher face-likeness (0.867 vs 0.640). What BFS adds is **scene
  coherence** — it is the only row that keeps the target's beret — plus the
  body-swap capability. We publish this because the lab's rule is measured
  truth, not marketing.
- Background + text survive: the neon **"FREE GPU LAB"** sign renders
  letter-perfect in every swap (it is the built-in canary), background SSIM
  vs the input scene 0.39–0.42 across all rows (unrelated-image floor: 0.08).

the subject's permission.

## Gotchas this repo already solved (each one invalidates a naive run)

1. **ComfyUI's autogrow `images` input takes FLAT dotted keys** (`"images.image_1"`)
   in the `/prompt` API. A nested `{"images": {...}}` dict *validates and
   executes with zero images bound* — every "swap" silently becomes plain
   text-to-image. This produced a full run of confident-looking garbage before
   we caught it by eyeballing outputs.
2. `QwenImage21Cache` needs explicit `device`/`dtype` in the API format.
3. The T4 needs the flag pair `--force-fp16 --disable-comfy-compiler`.
4. The "runtime hook" LoRA loader is broken on current ComfyUI master
   (`QwenImage21Transformer2DModel has no attribute 'diffusion_model'`) — the
   LoRAs load via stock merge here.
5. A crashed run leaves a zombie ComfyUI on port 8188 that answers health
   checks while the new server dies at bind — the pipeline kills it first.

Full stories in [references/05-troubleshooting.md](references/05-troubleshooting.md).
